# T‑Bank: статистика операций

Минимальный Flask-сервис для подсчёта покупок, продаж, комиссий и средних цен по истории брокерского счёта.

Отчёт можно ограничить одним тикером через необязательное текстовое поле; поиск точный и не зависит от регистра.

## Запуск

```bash
cd tbank_history_web
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5000>.

По умолчанию токен читается из `~/.tbank_token`. В файле должна быть одна строка с токеном (с префиксом `Bearer` или без него). Другой путь можно указать так:

```bash
TBANK_TOKEN_FILE=~/секреты/tbank-token python app.py
```

Для сервиса достаточно токена с доступом «только чтение». Не добавляйте файл токена в репозиторий.

## Правила расчёта

- поле «по» включается целиком; границы календарного дня считаются по Москве;
- количество берётся в штуках инструментов, как его возвращает API;
- средняя цена взвешена по количеству: сумма `цена × количество` / количество;
- результаты разбиваются по инструментам, а ниже дополнительно суммируются по валютам;
- инструменты разделяются на неполностью закрытые и закрытые внутри периода; для закрытых считается `PnL = продажи − покупки − комиссии`;
- для незакрытых считается условный PnL по последней доступной биржевой цене закрытия не позже конечной даты; будущая комиссия не учитывается;
- для `T` учтён сплит 1:10 от 15.04.2026: при пересекающем сплит периоде старые количества и цены приводятся к новой шкале;
- комиссии берутся по торговым операциям и показываются по валютам;
- используются исполненные покупки и продажи, включая маржинальные, карточные и поставочные операции, а также первичное размещение.

## Сравнение с TMON

Для рублёвых инструментов отчёт показывает прибыль альтернативного вложения в TMON и разницу `PnL бумаги − PnL TMON`. Каждая покупка вкладывает ту же сумму в дробные паи TMON без комиссии. Продажа закрывает соответствующее количество исходных бумаг по FIFO и связанную с ним долю TMON. Оставшиеся паи оцениваются на конечную дату отчёта. Используется последняя доступная дневная цена закрытия на дату операции (по Москве); поиск котировки ограничен предыдущими 14 днями. Комиссии реальных сделок остаются в PnL бумаги, налоги не учитываются.

Валютные инструменты, шорты и продажи позиций, приобретённых до выбранного периода, не сравниваются. При отсутствии котировок причина отображается в таблице, остальной отчёт остаётся доступен.

Опережение TMON в процентных пунктах рассчитывается как `(PnL бумаги − PnL TMON) / сумма покупок × 100`. Положительное значение означает опережение, отрицательное — отставание; показатель не приводится к годовой доходности.

Облигации (`instrumentType=bond`) исключаются из сравнения с TMON и загрузки котировок для этого сравнения; в основном отчёте они сохраняются.

## Купоны, погашения и дивиденды

В PnL включаются фактические купоны, дивиденды и погашения, а также удержанный налог с купонов и дивидендов за выбранный период. Они показаны отдельно в таблице выплат. Записи без тикера связываются с торговыми операциями по идентификаторам инструмента; неоднозначные выплаты не распределяются по догадке.

Для облигаций стоимость покупки/продажи берётся из `payment` API (денежный поток с НКД), комиссия учитывается отдельно. Частичное погашение добавляет денежный поток без изменения количества, полное — также уменьшает остаток. PnL открытых облигаций не отображается до реализации оценки по историческому номиналу и НКД: свеча в процентах номинала не является рублёвой ценой. Начальные позиции и их себестоимость до выбранного периода не восстанавливаются.

Для TMON гипотетические налоги не моделируются; фактический PnL бумаги учитывает удержанный налог с выплат.
