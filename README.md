# T‑Bank: статистика операций

Минимальный Flask-сервис для подсчёта покупок, продаж, комиссий и средних цен по истории брокерского счёта.

Отчёт можно ограничить одним тикером через необязательное текстовое поле; поиск точный и не зависит от регистра.

## Запуск

```bash
cd tmon
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5000>.

По умолчанию токен читается из `~/.tbank_token`. В файле должна быть одна строка с токеном (с префиксом `Bearer` или без него). Другой путь можно указать так:

```bash
TBANK_TOKEN_FILE=~/секреты/tbank-token python app.py
```

Для сервиса достаточно токена с доступом «только чтение». Не добавляйте файл токена в репозиторий.

## Правила расчёта

Границы календарного дня считаются по Москве; конечный день включается целиком.

PnL за выбранный период:

`стоимость на конец − стоимость на начало + продажи − покупки + купоны + дивиденды + погашения − налог с выплат − комиссии − чистый ввод бумаг`.

Начальные и конечные количества восстанавливаются назад от текущего `GetPortfolio` по истории всех типов операций с начала периода до текущего момента. Учитываются покупки, продажи, ввод/вывод бумаг и полные погашения. Для `T` учтён сплит 1:10 от 15.04.2026. Необработанные изменения количества приводят к отсутствию оценки строки, а не к предположению о нулевом остатке. Короткие позиции пока не оцениваются.

Начальная цена — последнее доступное закрытие до первого дня периода, конечная — закрытие не позже последнего дня. Поиск котировок ограничен предыдущими 14 днями. Позиции без сделок также включаются. Таблицы разделяются по наличию остатка на конец периода, сортируются по PnL. Суммарный PnL показывается отдельно по валютам и помечается неполным при отсутствии оценки хотя бы одной строки. Денежные результаты округляются до рублей только при отображении.

Для облигаций сделки учитываются по денежному `payment` API с НКД. Остатки оцениваются по формуле `количество × (котировка в процентах × исторический номинал / 100 + исторический НКД)`. Номинал и НКД берутся из `GetAccruedInterests` на соответствующую дату. Частичное погашение даёт денежный поток без уменьшения количества, полное также уменьшает остаток.

Купоны, дивиденды, погашения и удержанный с выплат налог включаются в PnL своего инструмента; их итог виден в колонке «Выплаты − налог». Операции без тикера связываются по идентификаторам инструмента. Даты выплат — фактические даты операций брокера, а не даты отсечек. Комиссии учитываются отдельно.

## Сравнение с TMON

Сравниваются только рублёвые инструменты, кроме облигаций. Начальная стоимость позиции условно вкладывается в дробные паи TMON по начальной цене, последующие покупки — в тех же суммах и на те же даты. Продажа закрывает соответствующую часть вложения по FIFO. Остаток TMON оценивается на конец периода. Используются цены закрытия; комиссии и гипотетические налоги TMON отсутствуют. При переводах бумаг сравнение пока недоступно.

Разница = `PnL бумаги − PnL TMON`. Под PnL показывается доходность `PnL / (начальная стоимость + сумма покупок) × 100%`. Под разницей — относительное превышение прибыли TMON: `(PnL бумаги / PnL TMON − 1) × 100%`; при прибыли TMON ≤ 0 показатель не показывается. Проценты не приводятся к годовой доходности.

Расчёт выполняется в фоне с отображением этапа и количества обработанных инструментов/дат. Задачи хранятся в памяти одного процесса и теряются при перезапуске сервиса.

## Локальный кеш

Успешные ответы API сохраняются в `.cache/api.sqlite3` (SQLite, сохраняется между перезапусками). Исторические котировки, НКД и номинал — на 24 часа, история операций прошлых месяцев — на час. Свежие котировки и НКД (за последние два дня) кешируются на 60 секунд. Свежие операции и текущий портфель не кешируются. Операции и свечи загружаются месячными блоками, поэтому повторные расчёты и соседние даты переиспользуют историю. Внутри одного расчёта одинаковые ответы API дополнительно переиспользуются в памяти. Ошибки API не сохраняются; ошибка кеша не мешает прямому запросу.

Кеш разделён по отпечатку токена; сам токен не сохраняется. Файл содержит финансовые данные и исключён из Git вместе с `.cache/`. Путь можно изменить через `TMON_CACHE_FILE`. Для полного обновления остановите сервис, удалите `.cache/api.sqlite3` и запустите сервис снова.

Последние отправленные значения формы (счёт, даты, тикер) сохраняются в таблице `settings` той же SQLite-базы без срока истечения. При открытии страницы они восстанавливаются; настройки разделены по отпечатку токена. Сохранение происходит после проверки счёта при запуске расчёта. Удаление базы сбрасывает также форму.
